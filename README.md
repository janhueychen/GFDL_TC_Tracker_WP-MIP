# WP-MIP GFDL Vortex Tracker Outputs
This repository contains the dataset of GFDL Vortex Tracker (Marchok 2021) outputs specifically for the WP-MIP. Introduction of the initial release (Version 0.0) can be found in "WP-MIP_GFDL_Vortex_Tracker_Outputs_v0.0.pdf". Comprehensive details regarding the dataset and its output formats are provided in "GFDL Vortex Tracker Format Instructions for WP-MIP.pdf".

Please cite [![DOI](https://zenodo.org/badge/1231233986.svg)](https://doi.org/10.5281/zenodo.20213965) when you use this dataset.
